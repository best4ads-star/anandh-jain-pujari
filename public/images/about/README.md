# About Page Image Architecture

This directory contains the image assets for the "About / My Story" page (`/about`).

### Primary Portrait Asset:
- `anandh-jain-pujari.jpg` — Authentic portrait of Anandh Jain Pujari used in the About Hero and My Journey sections.

### Optional Future Photography Assets:
- `journey.jpg` — Journey / timeline documentary photography asset
- `heritage.jpg` — Jain temple heritage & documentation photo asset
- `photography.jpg` — Heritage, temple architecture & field photography asset
- `design.jpg` — Graphic design, calligraphy & sacred typography asset

### To Update Images:
Simply drop your photographs with these exact filenames into `public/images/about/`.
The About page is architected to reference these paths directly (`/images/about/anandh-jain-pujari.jpg`, etc.).
